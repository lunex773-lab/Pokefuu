# pokefuu — Project Phantom（仮）

**Psychological Horror Creature RPG**
現代日本 × 都市伝説 × 心理ホラー × 怪異（クリーチャー）収集・育成。
トップビュー2DドットRPG（BW2風）をベースにした、完全オリジナル世界観のゲームです。

> 恐怖を倒すゲームではない。恐怖を理解し、受け入れ、乗り越える物語。

**クリアまで約10〜12時間**（全8章＋Final）を目標に制作中です。現在は **Chapter 1「学校」・Chapter 2「住宅街」** まで遊べます。
物語全体の構成とエンディング条件は [docs/STORY.md](docs/STORY.md) にあります。

🎮 **遊ぶ（ブラウザ／スマホ横画面）**：https://lunex773-lab.github.io/Pokefuu/ （main に push するたび自動で更新されます）

## 遊び方

```bash
npm install
npm run dev        # http://localhost:5173 （同じWi-Fiのスマホからは表示される Network URL で）
```

**iPhone の横向き** を前提にしています（画面の幅は端末の縦横比に合わせて自動調整し、ノッチやホームバーを避けて UI を配置します）。
Safari の共有メニューから「ホーム画面に追加」すると、アドレスバーのない全画面で遊べます。

| 操作 | スマホ | キーボード |
| --- | --- | --- |
| 移動（上下左右・マス目） | 画面左側をドラッグ（仮想スティック） | 矢印キー / WASD |
| 調べる・会話・決定 | 右下「調べる」 | Z / Enter / Space |

### ゲームの流れ

**Chapter 1「学校」**
1. 自室で目覚める（家族写真・引き出し・鏡を調べてみよう）
2. 朝霧町を通って桜ヶ丘高校へ。授業の後、湊と「十三階段」を確かめに行く
3. 踊り場の鏡から **裏層** へ。名前のない影「ナナシ」と出会う
4. 怪異を **鎮め → 封印し → 共鳴** して仲間にし、3体編成で育成する
5. 『視る』で隠された道を見つけ、ピアノの謎を解き、十三階段の主へ
6. 寄り道：昼休みに湊から預かる「七不思議調査」、図書室の「返ってこない本」、任意の探索エリア「裏・体育館」

**Chapter 2「住宅街」**（1章クリア後、自宅で眠ると始まる）
1. 朝霧町の東の道から、かつて家族が暮らした夕凪住宅街へ
2. 空き家の合鍵を手に入れ、夕方5時のチャイムの頃、板で塞がれた二階へ
3. 永遠の夕暮れの町で表札を集め、裏側の生家で「かくれんぼ」をし、封じられた子ども部屋へ

## 実装済みのシステム

- **探索**：32×32ドット、トップビュー、BW2風のマス目移動（上下左右の4方向のみ。※企画書の「8方向」から指示により変更）、室内・屋外・ダンジョン、NPC、調べる、隠し要素（視る）
- **現実 ⇄ 裏層**：裏層は時間が歪み（時刻固定）、危険度（Lv1〜7）で歪み演出・正気度減少が変化
- **昼夜（6区分）**：明け方／朝／昼／夕方／夜／深夜。NPC・イベント・出現・光・影が変化
- **天候**：晴れ・雨・霧・停電・赤い月（裏層の深夜）
- **ライティング**：ピクセルアート＋近代ライティング（光源・グロー・時間帯で向きが変わる影・水面反射・霧・画面歪み）。主人公の明かりは夜・裏層・停電など暗い所でだけ点き、スマホのライトは足元だけ、懐中電灯を装備すると向いている方向を照らす。夜は家々の窓ガラスがところどころ灯り、学校の照明は消える
- **戦闘**：ターン制・**3体編成**・7感情のタイプ相性・状態異常5種・スキル習得・主人公の行動（封印／道具／励ます／逃げる）
- **特性**：20体すべての怪異に、誕生理由に結びついた固有の特性（例：カゲボウシ「背中の影」＝夜・裏層で素早さ1.3倍）
- **強さをみる**：戦闘中に味方・敵のタイプ・相性・能力・特性・技の効果を確認（敵は共鳴したことのある怪異だけ詳しく見える）。メニューの怪異画面の「くわしく見る」でも同じ画面
- **仲間化**：HPを削る → 御札で封印 → 戦闘後に怪異の声を聞いて **共鳴**（応え方で成否が決まる）
- **レベル**：主人公レベル（正気度上限・共鳴力）と怪異レベルの両方
- **正気度**：裏層や怪異の精神攻撃で減少。0になると気絶して自室で目覚める
- **アイテム／クラフト／装備**：御札・御守り・数珠などを素材から作る。ライトの装備で照らせる範囲が変わる
- **図鑑**：怪異図鑑（誕生理由・伝承つき）／記憶片／用語辞典／章
- **実績**、**セーブ（3スロット）＋オートセーブ**、ショップ、睡眠
- **アルバイト**：コンビニの品出しミニゲーム（30秒で商品を正しい棚へ。並べた数で給料が決まる・1日1回）
- **サウンド**：音声ファイルを使わない手続き生成の環境音・効果音・BGM。BGMは静かで不気味な11曲（タイトルの子守唄・自宅・町の昼／夜・学校・店・無人の部屋・裏層2種・戦闘・ボス戦）。オルゴールや古いピアノの旋律が間をあけて鳴り、裏層では同じ子守唄が音程の狂った形で戻ってくる

## 技術構成

- TypeScript + [Phaser 3](https://phaser.io/)（WebGL）+ Vite
- 基準解像度 1920×1080、ワールドは 640×360 ドット相当を 3 倍表示
- グラフィックは **すべてコードで生成した仮ドット絵**（外部画像なし）。同じテクスチャキーで本番素材に差し替え可能
- 将来の Android / iPhone アプリ化は Capacitor でのラップを想定（[docs/ROADMAP.md](docs/ROADMAP.md)）

```bash
npm run typecheck   # 型チェック
npm test            # 単体テスト＋データ整合性テスト（vitest）
npm run build       # 本番ビルド（dist/）
npm run build:single  # 1つのHTMLファイルにまとめたビルド（dist-single/pokefuu.html）。ファイルを開くだけで遊べる
```

# pokefuu — Project Phantom（仮）

**Psychological Horror Creature RPG**
現代日本 × 都市伝説 × 心理ホラー × 怪異（クリーチャー）収集・育成。
トップビュー2DドットRPG（BW2風）をベースにした、完全オリジナル世界観のゲームです。

> 恐怖を倒すゲームではない。恐怖を理解し、受け入れ、乗り越える物語。

現在のバージョンは **Chapter 1「学校」の縦切り版（バーティカルスライス）** です。
全8章＋Final のうち第1章を、ゲームの全システムを通して遊べる形で実装しています。

---

## 遊び方

```bash
npm install
npm run dev        # http://localhost:5173 （同じWi-Fiのスマホからは表示される Network URL で）
```

スマホでは **横画面** で遊んでください。

| 操作 | スマホ | キーボード |
| --- | --- | --- |
| 移動（8方向） | 画面左側をドラッグ（仮想スティック） | 矢印キー / WASD |
| 調べる・会話・決定 | 右下「調べる」 | Z / Enter / Space |
| 視る（歪みを探す） | 右「視る」 | C |
| ダッシュ | 右「ダッシュ」を押しながら | Shift |
| メニュー | 右上「メニュー」 | Esc / M |
| キャンセル | ― | X / Backspace |

### ゲームの流れ（第1章）

1. 自室で目覚める（家族写真・引き出し・鏡を調べてみよう）
2. 朝霧町を通って桜ヶ丘高校へ。授業の後、湊と「十三階段」を確かめに行く
3. 踊り場の鏡から **裏層** へ。名前のない影「ナナシ」と出会う
4. 怪異を **鎮め → 封印し → 共鳴** して仲間にし、3体編成で育成する
5. 『視る』で隠された道を見つけ、ピアノの謎を解き、十三階段の主へ

## 実装済みのシステム

- **探索**：32×32ドット、トップビュー、8方向歩行、室内・屋外・ダンジョン、NPC、調べる、隠し要素（視る）
- **現実 ⇄ 裏層**：裏層は時間が歪み（時刻固定）、危険度（Lv1〜7）で歪み演出・正気度減少が変化
- **昼夜（6区分）**：明け方／朝／昼／夕方／夜／深夜。NPC・イベント・出現・光・影が変化
- **天候**：晴れ・雨・霧・停電・赤い月（裏層の深夜）
- **ライティング**：ピクセルアート＋近代ライティング（光源・グロー・懐中電灯の円錐光・時間帯で向きが変わる影・水面反射・霧・画面歪み）
- **戦闘**：ターン制・**3体編成**・7感情のタイプ相性・状態異常5種・スキル習得・主人公の行動（封印／道具／励ます／逃げる）
- **仲間化**：HPを削る → 御札で封印 → 戦闘後に怪異の声を聞いて **共鳴**（応え方で成否が決まる）
- **レベル**：主人公レベル（正気度上限・共鳴力）と怪異レベルの両方
- **正気度**：裏層や怪異の精神攻撃で減少。0になると気絶して自室で目覚める
- **アイテム／クラフト／装備**：御札・御守り・数珠などを素材から作る。ライトの装備で照らせる範囲が変わる
- **図鑑**：怪異図鑑（誕生理由・伝承つき）／記憶片／用語辞典／章
- **実績**、**セーブ（3スロット）＋オートセーブ**、ショップ、アルバイト、睡眠
- **サウンド**：音声ファイルを使わない手続き生成の環境音・効果音（BGMは最小限、静寂を多用）

## 技術構成

- TypeScript + [Phaser 3](https://phaser.io/)（WebGL）+ Vite
- 基準解像度 1920×1080、ワールドは 640×360 ドット相当を 3 倍表示
- グラフィックは **すべてコードで生成した仮ドット絵**（外部画像なし）。同じテクスチャキーで本番素材に差し替え可能
- 将来の Android / iPhone アプリ化は Capacitor でのラップを想定（[docs/ROADMAP.md](docs/ROADMAP.md)）

```bash
npm run typecheck   # 型チェック
npm test            # 単体テスト＋データ整合性テスト（vitest）
npm run build       # 本番ビルド（dist/）
npm run build:single  # 1つのHTMLファイルにまとめたビルド（dist-single/pokefuu.html）。ファイルを開くだけで遊べる
```
